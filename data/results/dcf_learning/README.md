# Stepwise Nike DCF results

Run `research/model_nke_dcf.ipynb` to populate this directory with the rewritten model's tables and charts. The notebook is saved without executed outputs.

The valuation cutoff is September 15, 2026 at 4 p.m. New York time. Expected outputs include historical anchors, assumptions, WACC, cash-flow forecasts, terminal schedules, fundamental valuations, sensitivity, scored news, sentiment aggregation, final price comparisons, the model-derived price-target and rating summaries, and source ledgers. Expected charts include forecast paths, DCF sensitivity, historical performance, base-case FCFF, enterprise-value composition, the sentiment comparison, the overall price-target range, the Buy/Hold/Sell rating gauge, and the six-panel equity-research dashboard. A manifest records the execution date and model version when run.

Files directly in the parent `data/results` directory were generated by the previous model and must not be treated as results of this rewrite. This version has three operating scenarios and a bounded sentiment adjustment applied only after the fundamental valuation.
